# Reusable rainy-night assets

## Rain overlay

- File: `rain-overlay-128.webp`
- Size: 128 × 128 px
- Animation: 8 frames at 8 fps, seamless loop
- Source: Pixel Engine
- Cost at creation: 26 monthly credits total (6-credit sprite + 20-credit animation); 74 credits remained

### VN usage
1. Import as a foreground layer above the background.
2. Scale to fill the 9:16 canvas.
3. Lower opacity so rain supports rather than hides the subject.
4. Extend across the shot and keep direction consistent across adjacent clips.
5. Verify animated WebP support in your VN version; convert to a supported video/PNG sequence if necessary.
