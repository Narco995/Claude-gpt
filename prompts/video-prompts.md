# Video Prompt Templates

## Image-to-video shot
Animate the supplied image without redesigning anything. Preserve the exact character, pixel-art rendering, composition, palette, and environment. Action: [ONE SIMPLE ACTION]. Ambient motion: [RAIN / STEAM / LIGHT FLICKER / REFLECTIONS]. Camera: [LOCKED / VERY SLOW PUSH-IN / SUBTLE PAN]. Smooth restrained movement, stable geometry, no cuts, no new objects, no text.

## Looping ambience
Create a seamless subtle loop from the supplied scene. Keep the camera locked. Animate only [RAIN / STEAM / NEON FLICKER / WATER RIPPLE]. First and last frames should match. Preserve all shapes and details.

## Shot safety rules
- One primary action per clip.
- Prefer 4–6 second clips that can be trimmed.
- Avoid asking the model to change camera, location, and character action simultaneously.
- Generate separate clips for separate story beats.
- Inspect frame-to-frame consistency before editing.
